# e-commerce-platform

This repository contains **CloudResilience**, an Infrastructure-as-Code based Business Continuity and Disaster Recovery (BCDR) framework for a multi-zone microservices application.

All project code and documentation live in [`bcp-dr/`](bcp-dr/). Start with:

- [bcp-dr/README.md](bcp-dr/README.md) — the application and how to run it
- [bcp-dr/PROJECT_ROADMAP.md](bcp-dr/PROJECT_ROADMAP.md) — project plan, current phase and decisions

Run all `npm` commands from inside `bcp-dr/` (see [decision 0002](bcp-dr/docs/decisions/0002-repository-root.md)).
